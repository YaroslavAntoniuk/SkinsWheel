# Таблиці паттернів (фаза 4)

`patterns/<тип>/<зброя>.json` — відповідність сід → тір для одного скіна.
Кожен сід має поле `source` (мінімум два джерела); якщо джерела розходяться,
береться нижчий тір і ставиться `disputed: true`.

Колесо паттерна показується лише для скінів, для яких тут є таблиця.
Поки таблиць немає, тому сід показується лише числом.
