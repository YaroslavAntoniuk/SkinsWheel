# Changelog

## Unreleased

- Колесо паттерна після зношення: Fade / Amber Fade / Acid Fade (тіри за Fade %) і Case Hardened / Heat Treated (тіри за % синього). Ширина тіру = частка сідів, колесо зупиняється на тірі випалого сіду, підпис — сід і точне значення.
- `pnpm sync-patterns`: таблиці з chescos/csgo-fade-percentage-calculator і chescos/csgo-blue-gem-calculator (MIT) на зафіксованих комітах; валідатор перевіряє їх проти даних скінів.
- Сід ножів і рукавичок тепер 0–999 (1000 — лише з контрактів обміну).

- Налаштування (`S`): список слотів — група («будь-який ніж») або конкретна зброя (M4A4, Desert Eagle…), порядок, пресети, нік глядача, швидкий спін. Слоти й нік зберігаються в URL.
- Кожен слот крутиться ланцюжком коліс із заголовком: зброя (якщо слот — група) → скін → фаза Doppler → зношення.
- Колесо скіна показує всі фініші зброї (Doppler — один сегмент, фаза окремим колесом), а не 12 випадкових.
- Колесо наступного етапу з'являється одразу, ще до спіну; переможний сегмент підсвічується, назва показується під колесом.
- Картинки скінів у сегментах, підписи на лівій половині не перевернуті.

- Каркас проєкту: Vite + TypeScript, Vitest, CI з валідатором і деплоєм на GitHub Pages, шаблон PR з трьома гейтами.
- `sync-data`: ByMykel CSGO-API на зафіксованому коміті → `data/skins.json` (2126 записів) + `data/meta.json`.
- Валідатор даних і `isPossible(skin, roll)`; автоспіни в `pnpm validate`.
- Рушій ролів: флоат через сирий рол і ремап у діапазон скіна, аналітичні шанси зношення, StatTrak / Souvenir, сід 0–1000, сідований генератор (лоадаут відтворюється за кодом).
- Мінімальне Canvas-колесо: 5 слотів (ніж → рукавички → гвинтівка → снайперка → пістолет), колесо зношення з реальними шансами скіна, картка результату, хоткеї Space / N.
